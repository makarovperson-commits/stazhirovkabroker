# Дневник стажёра

Стажировка брокера (до старта, программа 4 недели) и ежедневный отчёт.

- Брокер открывает страницу, заполняет отчёт дня. Данные хранятся в его браузере.
- Раз в неделю: «Стажировка» → «Скачать отчёт за неделю» → отправить файл РОП.
- РОП: вкладка «Свод РОП» → «Загрузить отчёты» → свод по неделям и месяцам.
