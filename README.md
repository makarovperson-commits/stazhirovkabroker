# Дневник стажёра

Стажировка брокера (до старта, программа 4 недели) и ежедневный отчёт.

- Брокер открывает https://makarovperson-commits.github.io/stazhirovkabroker/ и заполняет отчёт дня.
- Каждый сохранённый день уходит в Google-таблицу РОП (`apps-script.gs`).
- РОП открывает ту же ссылку → вкладка «Свод РОП» → пароль → свод по неделям и месяцам.

Настройка хранилища: создать Google-таблицу → Расширения → Apps Script → вставить `apps-script.gs`,
вписать пароль РОП → Развернуть → Веб-приложение (выполнять от имени: я, доступ: все) →
ссылку вставить в `config.js`.
